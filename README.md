# Estudos em Python 🐍

Repositório dedicado ao aprendizado, prática e desenvolvimento de projetos, scripts e jogos em **Python**.

---

## 📁 Projetos e Estrutura

- **[Urna Eletrônica](./Urna%20Eletronica/)**: Simulador gráfico de urna eletrônica desenvolvido com **Pygame**, contendo teclado interativo, sons visuais e validação de candidatos.
- **[Falling Leaves](./FallingLeaves_arrumar/)**: Animação gráfica interativa de folhas de outono caindo feita com **Tkinter Canvas**.
- **[WiFi Infos](./WiFi%20Infos/)**: Conjunto de scripts para obtenção e diagnóstico de informações de redes Wi-Fi (status de conexão, intensidade de sinal, adaptadores e perfis).
- **[SpeedTest](./SpeedTest/)**: Script para medição de velocidade de download e upload da conexão com a internet.
- **`campo_minado.py`**: Jogo clássico de Campo Minado.
- **`tetris.py`**: Implementação clássica do jogo Tetris.

---

## 🚀 Como Executar

1. **Pré-requisitos**:
   - Python 3.10+ instalado.

2. **Instalação das dependências comuns** (para projetos com interface gráfica/bibliotecas externas):
   ```bash
   pip install pygame
   ```

3. **Executando um projeto**:
   ```bash
   # Exemplo: Urna Eletrônica
   python "Urna Eletronica/urna.py"

   # Exemplo: Animação de Folhas
   python "FallingLeaves_arrumar/animation.py"

   # Exemplo: Tetris
   python tetris.py
   ```
